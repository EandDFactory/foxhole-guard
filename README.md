# Foxhole Guard 🛡️

Advanced secure tunnel and runtime manager for Android with Dynamic Protocol & Route Hopping capabilities.

## Features
- **Dynamic Protocol Hopping**: Automatically shifts tunneling protocols (REALITY, gRPC, Xhttp, TLS) to bypass advanced DPI filters.
- **Modular Runtime**: Clean, customizable architecture designed for high-performance secure networking on Android.
- **Fully Open & Customizable**: No restricted modules or locked-down layers; every component can be easily tailored to your needs.
